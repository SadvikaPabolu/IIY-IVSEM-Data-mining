# 📊 Student Academic Performance Analysis

> Turning student data into meaningful insights using Data Mining 🚀

---

## 📌 Overview
This project explores how data mining techniques can be used to analyze and predict student academic performance. By combining academic results with student activity data, the system uncovers hidden patterns and relationships that influence success in education.

---

## 🎯 What This Project Does
✔️ Analyzes student performance data  
✔️ Identifies key factors affecting academic success  
✔️ Predicts student outcomes using machine learning  
✔️ Discovers patterns in student behavior and study habits  

---

## 📂 Dataset Description
The project uses two real-world datasets:

**📘 Academic Data**
- Marks  
- Total Score  
- Grades  

**📗 Activity Data**
- Attendance  
- Study Hours  
- Assignment Completion  
- Participation Level  

These datasets are merged using a common identifier to create a complete view of student performance.

---

## ⚙️ Tech Stack
- 🐍 Python  
- 📊 Pandas  
- 📈 Matplotlib  
- 🤖 WEKA  

---

## 🔄 Data Processing Pipeline
- Data Cleaning (handling missing & inconsistent values)  
- Data Transformation & Normalization  
- Noise Removal & Validation  
- Data Visualization for insights  

---

## 🧠 Applied Techniques

### 🔹 Classification
Predicting student performance using:
- Decision Tree (J48)  
- Random Forest  

### 🔹 Clustering
Grouping students based on similarities:
- K-Means Clustering  
- Hierarchical Clustering  

### 🔹 Association Rule Mining
Finding relationships between attributes:
- Apriori Algorithm  
- FP-Growth  

---

## 📊 Key Insights
✨ Random Forest achieved the best prediction accuracy  
✨ Student activity (attendance & study hours) strongly impacts performance  
✨ Clustering reveals distinct student performance groups  
✨ Association rules uncover hidden behavioral patterns  

---

## ✅ Conclusion
This project highlights the power of data mining in education. By combining multiple data sources and applying machine learning techniques, it becomes possible to better understand, predict, and improve student performance.
